# Conversor de Fahrenheit para Celsius

Exercício de PHP com um formulário HTML para informar uma temperatura em Fahrenheit e exibir o resultado em Celsius.

## Executar

Com PHP instalado, abra um terminal nesta pasta e execute:

```powershell
php -S localhost:8000
```

Depois, acesse `http://localhost:8000`.
